REGEX:
letter	(matches itself)
^	(if at start of regex expression it must match at the start of line)
$	(if at end of regex expression it must match at end of line)
.	(any single character)
*	(the previous character repeated 0 or more times)
[ ]	(A list "," or range "-" or characters to match one character)
[^ ]	(A list "," or range "-" of characters to ignore when matching the character) ^ at beginning

EXAMPLES FROM A FILE WHICH IS A COLUMN OF WORDS:
grep '^....$' regex-practice.txt	(four letter words)
grep '.*ter' regex-practice.txt	 	(words containing 0 or more letters then "ter" somewhere in them)
grep '^[^a]' somefile			(words not containing "a" at the beginning)
grep '^h.....$' regex-practice.txt	(six letter words starting with h)
ascii -d		(print the decimal ascii table)

REGEX EXTENDED: grep -E	OR egrep
?	(matches previous character 0 or 1 time)
+	(matches previous character 1 or more times)
|	(logical or)
( )	(grouping letters, alternation expression)
{n}	(range specifier - repeat n times)
EXAMPLES:
grep -E '.*j+.*' regex-practice.txt	(find all words containing the letter j at least once)
grep -E 'colou?r'			(find the word colour but with both UK and US spelling)
grep -E 'tango|zulu' regex-practice.txt	(find the word tango or zulu)
ls -l | grep -E '(..a){2}' 		(find all lines with ..a..a pattern in them)
grep -E '.*(.e){2}.*' home*		(example of grep * (zero or more) and shell globbing home* (followed by any group of chars)
grep -E 'a{3,4}' as.txt			(show all lines with aaa or aaaa in them somewhere)	
grep -E 'a{3,}' as.txt			(show all lines with three or more a's together aaa, aaaa, aaaaa... etc)
ls -la | grep -oE '(exa)|(mma)'		(only show the part of the file that contains the match, not the whole line)
ls -la | grep -EA 3 '(exa)|(mma)'	(show 3 lines of context after the term was found, maybe if you wanted to see some code around a word?)


ARCHIVE AND COMPRESSION:

gzip -r someDir				(compress all files in a directory from outside it, r=recursive)

TAR (Create Mode)
tar -cf mytarfile.tar file*		(collect all files starting with "file" into a tarball called mytarfile)
tar -czf mytarfile.tar.gz file*		(collect all files into a tarball and then zip them with gzip to compress)
tar -czf mytarfile.tgz file*		(alternate convention for zipped tarball suffix)
gzip -l mytarfile.tgz			(show info on compression of tarball)
(List Mode)
tar -tzf sometarball.tar.gz 		(list the contents of the tarball recursively)
(Extract Mode)
tar -xf sometarball.tgz			(extracts all files from the tarball decompressed)
tar -xzf sometarball.tar.gz		(extracts all files from the tarball and lists what was extracted)
ZIP FILES:
zip -r zipfile.zip somedir		(zip a directory recursively)
zip zipfile.zip	file*			(zip all files starting in file)
